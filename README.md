# 西域時序 · 中央アジア時代変遷地図 (Central Asia Historical Atlas, 1162–1949)

チンギス・ハーン生誕（1162年）から中華人民共和国成立（1949年）までの787年間にわたる中央アジア（マー・ワラー・アンナフル、ホラズム、フェルガナ、セミレチエ、タリム盆地、ジュンガリア、モンゴル高原、ホラーサーン）の時代変遷・歴史疆域・政区・都市沿革・人物行跡をインタラクティブに可視化した歴史地図システムです。

- **公開URL**: https://aki-asahi.com/hobby/CentralAsia-map/

---

## 主な特徴

1. **9つの歴史時代・33段階の詳細スナップショット（1162年〜1949年）**
   - **カラ・キタイとホラズム**（1162〜1205年）
   - **モンゴル帝国勃興と中央アジア征服**（1206〜1227年）
   - **モンゴル帝国と四大ウルス形成**（1228〜1259年）
   - **ハイドゥ・ウルスとチャガタイ・ハン国**（1260〜1369年）
   - **ティムール朝とモグーリスタン**（1370〜1500年）
   - **ウズベク三ハン国・カザフ・ヤルカンド**（1501〜1639年）
   - **ジュンガル・ハン国と清朝の攻防**（1640〜1758年）
   - **清朝新疆統治とロシアの中央アジア南下**（1759〜1916年）
   - **ロシア革命・ソ連中央アジア5共和国成立と民国期新疆**（1917〜1949年）

2. **地名表記ルール（日本語最適化）**
   - **中央アジア・ステップ・イラン・モンゴル圏**: カタカナ表記（`ビシュバリク`、`サマルカンド`、`ブハラ`、`ヒヴァ`、`ウルゲンチ`、`コーカンド`、`タシュケント`、`オトラル`、`ベラサグン` 等）
   - **タリム盆地・トルファン・ハミのオアシス都市**: カタカナ＋歴史漢字併記（`ホータン（于闐）`、`カシュガル（喀什噶爾）`、`ヤルカンド（葉爾羌）`、`アクス（阿克蘇）`、`クチャ（亀茲）`、`トルファン（高昌）`、`ハミ（哈密）` 等）
   - **中国本土・河西回廊**: 漢字表記（`敦煌`、`酒泉`、`張掖`、`武威`、`蘭州` 等）

3. **都市沿革・歴史人物行跡・街道ネットワーク**
   - 主要オアシス都市・草原都城の通時沿革（「拠点沿革」）
   - 耶律大石・チンギス・ハーン・長春真人丘処機・ティムール・バーブル・ガルダン・左宗棠らの歴史行跡
   - 天山北路・天山南路・西域南道・オアシス幹線・トランス＝カスピ鉄道・トルキスタン＝シベリア鉄道
